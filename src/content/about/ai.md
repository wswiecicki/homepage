I work on both sides of AI systems: validating them and building them. On the validation side, that means evaluation harnesses for non-deterministic output, LLM-as-judge pipelines, regression suites for agentic behaviour, and the guardrails that make agent deployments safe to ship. On the build side, fine-tuning, RAG systems, agent-to-agent orchestration, and custom agents for real workflows. Testing agents well requires having built them - the failure modes only become obvious from the inside.
