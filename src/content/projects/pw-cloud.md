Architected, deployed, managed and tested a solution for running Playwright tests in Azure in a scalable manner, using a custom GUI.

Basic architecture consisted of: App Service, Storage Queues, Azure Container Apps, App Gateway and Application Insights.

Used technologies such as Teraform, React, FastAPI, Dotnet, WebSockets, Electron, k6, Docker.

Comprehensive testing was done using such methods as unit, component, integration, end-to-end and property-based testing.

Swarming large numbers of clients for stress testing was made possible using Playwright scripts.
