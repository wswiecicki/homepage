Designed and built a desktop test automation recording solution combining Playwright, NutJS and an in-house AI integration.

Playwright test runner provided the execution layer, NutJS desktop interactions, and the AI layer translated recorded user sessions into test scripts.

The result was a recorder capable of capturing end-to-end flows that span browser and desktop - and producing maintainable and deterministic test code.
