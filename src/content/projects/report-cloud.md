Designed and deployed an online raport generator with data aggregation.

Data from automated tests using Selenium, Cypress, Playwright, Lighthouse, Axe and Vitest were correlated and raports in a specific format were generated and stored.

Technologies such as Ligthouse Server, Azure CosmosDB, Azure Functions were used.
