Built an autonomous exploratory testing agent using PydanticAI on top of a Databricks-hosted model and data platform.

The agent reasons about application state, makes decisions based on code deltas, plans exploration paths, creates invariants, then drives the system under test and finds issues. It augments daily workflows and speeds up the development process.

Databricks was used for model serving and agent creation. PydanticAI simplified the implementation and provided many tools out of the box.
